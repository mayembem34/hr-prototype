# Training management

Run `php artisan migrate` after deployment. The catalogue supports course details and optional external HTTP(S) delivery links. YouTube watch, short, embed, live and youtu.be links are embedded in the staff catalogue and in approved or directly assigned employee training; other HTTP(S) URLs remain links. YouTube controls video availability, embedding and privacy; the platform does not host course content. Organization administrators and delegated roles can create and update courses. Assignment permissions support own, unit, nested-unit and organization scopes. Individual, unit and organization assignment creates a snapshot of active employees, and skips existing course/employee assignments; choosing the organization requires organization-wide assignment permission. Unit selection requires unit-view permission, and assignment fails if any selected active employee is outside the actor's assignment scope. Re-run an assignment to include new employees. Existing development training records remain separate.

Employees can request enrolment; an authorized reviewer approves or rejects it. Direct assignments require no enrolment approval. Employees or permitted staff record progress, and can upload certificates after completion. Completion and certificates are self-reported, not verified credentials. Certificates are private files. Assigned employees receive in-system notifications; Laravel scheduler sends in-system reminders daily for incomplete training due within seven days or overdue, once per day. Configure the server cron to run `php artisan schedule:run` every minute; `php artisan training:remind` can run reminders manually. Reports count assignments within the report permission scope. In-system reminders are not emails or push notifications.

Each employee may have one assignment per course; repeat enrolment and resubmission of rejected requests are not supported in this version. There is no course-hosting, e-learning player, certificate generation or assessment engine.
