# Employee profile setup

An organization administrator adds a user account under Members and sets an initial password. There is no public registration. The user signs in, then completes their own profile. A user with one organization and no linked employee profile is sent to profile setup after sign-in; users with multiple organizations can choose My employee profile on the home page. An existing employee record should be linked by an authorized administrator before the user completes their profile to avoid a duplicate.

The user can enter name, contact email, phone, date of birth, address and emergency contact details. Their sign-in email is separate from their contact email. A new profile receives an automatically generated temporary employee number. HR controls the official employee number, unit, reporting manager, employment status and employment details. Self-service changes are added to employee change history. Each profile is linked to the signed-in user and organization, and no other user's profile can be edited through self-service.

Each new organization receives an unassigned HR Manager role with organization-wide employee viewing and document listing, preview and download permissions. The migration adds this suggested role to existing organizations that do not already have one. It does not alter a pre-existing role of the same name. The administrator must assign the role to the appropriate people and may adjust it. Additional HR permissions, such as employee updates, can be granted separately.

The migration adds `profile.self.view` and `profile.self.update` as permissions for authenticated organization members, and the privileged `members.accounts.create` permission for organization administrators. The existing `members.add` permission can add an already registered user to an organization, but only administrators can create a new user account.
